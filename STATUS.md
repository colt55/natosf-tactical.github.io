# SENTINEL Public Deployment Status

Current public website baseline: **SENTINEL V2.04.79**.

SENTINEL is a multi-terrain deployment campaign. The public site intentionally does not bind the campaign identity to one terrain.

Your SENTINEL career moves with the campaign. Rank and specialization progress continue across deployments, while the multiplayer lobby slot assigns the active Operator Role for each session.

The authoritative playable mission is the current versioned SENTINEL build, not this repository.
